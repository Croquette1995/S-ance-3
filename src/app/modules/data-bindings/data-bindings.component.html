Bac à Sable des Liaisons de Données (Template Bindings)

Expérimentez en direct les 3 formes fondamentales de liaison de données d'Angular entre la classe TypeScript et la vue HTML.

1. Interpolation &#123;&#123; expression &#125;&#125; TS -> HTML

Injecte le résultat d'une expression ou variable TypeScript directement sous forme de texte dans le DOM.

Rendu HTML en direct
Bonjour {{ studentName() }} !
Inscrit au cours : {{ courseTitle() }} 
&lt;h5&gt;Bonjour &#123;&#123; studentName &#125;&#125;&lt;/h5&gt;
2. Property Binding [propriété]="valeur" TS -> HTML Element

Lie dynamiquement une propriété d'un élément HTML (ex: disabled, src, class) à une variable TypeScript.

Rendu HTML en direct
{{ badgeStatus() === 'online' ? 'En Ligne' : 'Hors Ligne' }} 
&lt;button [disabled]="isButtonDisabled"&gt;Soumettre&lt;/button&gt;
3. Event Binding (événement)="méthode()" HTML -> TS

Écoute les événements du DOM (clic, survol, saisie) et déclenche une méthode de la classe TypeScript.

Rendu HTML en direct

Compteur : {{ clickCounter() }}

{{ lastActionLog() }} 
&lt;button (click)="incrementCounter()"&gt;Incrémenter&lt;/button&gt;
