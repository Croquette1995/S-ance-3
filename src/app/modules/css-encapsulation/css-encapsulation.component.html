Démonstrateur d'Encapsulation CSS (ViewEncapsulation)

Comprenez comment Angular isole automatiquement les règles CSS d'un composant grâce à l'injection d'attributs d'encapsulation (ex: _ngcontent-ng-c123456).

ARBORESCENCE & STYLES EN DIRECT ViewEncapsulation.Emulated
<app-root> (Composant Parent) Attr: {{ parentAttribute }}

Je suis un paragraphe <p> dans le Composant PARENT.

<app-header> (Composant Enfant) Attr: {{ childAttribute }}

Je suis un paragraphe <p> dans le Composant ENFANT (Ciblé par la règle CSS).

Notez que le paragraphe du parent reste insensible à la règle CSS définie dans l'enfant !
INSPECTEUR DE COMPILATION CSS ANGULAR CODE COMPILÉ
Code CSS d'origine (dans header.component.css) : 
p {
  color: {{ childColor() }};
  font-style: {{ childFontStyle() }};
}
Code CSS RÉÉCRIT par Angular à la compilation : 
p[{{ childAttribute }}] {
  color: {{ childColor() }};
  font-style: {{ childFontStyle() }};
}
Rendu DOM généré dans le navigateur : 
<!-- Parent -->
<p {{ parentAttribute }}>Paragraphe Parent</p>

<!-- Enfant -->
<p {{ childAttribute }}>Paragraphe Enfant</p>
